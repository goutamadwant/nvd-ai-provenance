# Security Policy

## Scope

This repository contains a prototype schema, validator, and synthetic test
data. It is not an operational vulnerability database or remediation system.

## Reporting

Do not open a public issue containing credentials, personal data, proprietary
information, or unpublished vulnerability details. Use GitHub's private
vulnerability reporting feature when it is available for this repository. For
ordinary correctness or interoperability issues that contain no sensitive
information, open a public issue.

## Supported Version

Only the latest commit on the default branch is maintained during the draft
phase.
